## Reporting a Vulnerability

Please report vulnerabilities through GitHub private vulnerability reporting:
https://github.com/idempiere/idempiere/security/advisories/new

The report stays private between you and the iDempiere security team until a fix is released.

If you do not have a GitHub account, send an email to security@idempiere.com. The security team will register your report as a private advisory.

A good report includes:

- The affected version(s)
- Steps to reproduce
- The impact
- Whether you want to coordinate the disclosure timing

Please do not open public issues, forum posts or Mattermost messages about vulnerabilities.

The full process is described in [How to report a vulnerability](https://docs.idempiere.org/docs/basic-development/contributing-to-core/how-to-report-a-vulnerability).
